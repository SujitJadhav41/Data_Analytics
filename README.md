# 📊 Data_Analytics

A collection of Python projects and practice programs focused on improving programming, automation, problem-solving, and data analysis skills.

## 🚀 About

This repository contains beginner to intermediate Python projects created while learning Data Analytics and Python programming. It includes automation scripts, games, and utility programs.

## 📁 Projects

### 🧮 Calculator
A simple Python calculator that performs basic arithmetic operations.

**Features**
- Addition
- Subtraction
- Multiplication
- Division

**File**
- `calculator.py`

---

### 📂 File Organizer
A Python automation script that organizes files into folders based on their file extensions.

**Features**
- Automatically sorts files
- Creates folders if they don't exist
- Supports multiple file types
- Helps keep directories organized

**Folder**
- `file_organizer/`

---

### 🎮 Snake, Water, Gun Game
A Python implementation of the classic Snake-Water-Gun game.

**Features**
- User vs Computer
- Random computer choice
- Score calculation
- Easy command-line interface

**Files**
- `game/`
- `snake_game.py`
